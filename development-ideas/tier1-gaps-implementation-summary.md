## Method
- Every index-group subject is compared with every reference-group subject; each pair is a
  **win / loss / tie** decided by the first endpoint (in priority order) able to order it.
- Time-to-event rule: a pair is decided only when one subject's event time is exceeded by the
  other's follow-up, so censored-unorderable pairs stay ties (standard Pocock 2012 unmatched WR).
- Reports **win ratio** (wins/losses), **win odds** (ties split), **net benefit** ((W−L)/total).
- **Analytic CI**: variance of log(WR) from per-subject win/loss proportions, Dong et al. (2016).
- **Bootstrap CI**: subject-level resampling within each arm.

## Validation performed (managed R 4.5.3, engine mirrored outside jamovi)
- Analytic point estimate & CI reproduced by a 400-rep subject-level bootstrap
  (WR 1.635 vs bootstrap median 1.637; CI [1.20,2.23] vs [1.18,2.28]).
- Direction/magnitude consistent with Cox `1/HR` (1.55) on the same data.
- 3-tier hierarchy verified: ties fall to 0 as lower-priority endpoints break them;
  endpoint-contribution counts sum correctly to W+L.
- No-losses edge case returns WR = Inf with SE/CI/p set to NA (guarded).
