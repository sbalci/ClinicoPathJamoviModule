## 5. EDGE CASES & CLINICAL SAFETY GUARDS

| # | Condition | Input Data | Expected Outcome |
|---|---|---|---|
| 18 | Empty selection | `dep = NULL` | Theme-safe welcome card in `todo`; no crash |
| 19 | Small sample & small groups | `jjhistostats_small` (`dep = "score"`, `grvar = "group"`) | Small-*n* (<30), small-group (<10), and Wilcoxon `exact = FALSE` disclosures in `todo` |
| 20 | `n < 3` and constant subgroups | Synthetic grouped data with $n = 1$, $n = 2$, constant, and all-NA groups | Refusal subtitle on `n = 1` / `n = 2` (never Hedges' $g = 0.00 [0.00, 0.00]$); no `"Random seed:"` caption on constant/refused plots |
| 21 | Heavy ties in trimmed core (`trimse == 0`) | `c(1, 5, 5, 5, 5, 5, 5, 5, 9)`, `typestatistics = "robust"`, `trimlevel = 0.2` | Refuses test cleanly (no `t = Inf`) in both two-sided and one-sided modes |
| 22 | Extreme directional Bayes evidence & opposite-sign data | `rnorm(200, 50, 1)` and `rnorm(25, -2, 1)`, `typestatistics = "bayes"`, `alternative = "greater"` | Finite `log_e(BF_01)` (no `exp()` overflow) and finite negative posterior median/ETI (never `Inf [Inf, Inf]`) |
| 23 | Precision boundaries | `conf.level = 0.999` (shows `99.9%`, not `100%`); `digits = 5` robust zero-exceedance (`p < 0.005`, never `2.225e-308`); Shapiro–Wilk `p < 1e-16` (no `p = <`) | Exact boundary formatting |
| 24 | Missing / `addNA()` / unused factor levels & non-syntactic names | `addNA()` factor with unused level, NA-depleted group, column `"Age (years) / Grade+"` | No crash; flags NA-depleted group; ignores unused level; renders safely |
| 25 | Excessive bins (`max_bins > 5000`) | `seq(0, 1.5e6, length.out = 20)` with `clinicalPreset = "pathology_scores"` or `binwidth = 1` | Clean `jmvcore::reject()` before mutating `todo` |
| 26 | Invalid types / non-finite values | Factor `dep`, `Inf`/`-Inf`, `n = 2`, 0-row data | Actionable `jmvcore::reject()` messages; `NaN` sanitized to `NA` |
