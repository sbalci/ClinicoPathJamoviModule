## 3. Code changes in this pass (`R/decisioncompare.b.R`)

These are the changes that strings needed before they could be translated. The English output
is unchanged.

1. **Comparison labels are translatable.** The table cell text "A vs B" was built with `paste()`:

   ```r
   comparison_labels[i] <- .fmt(jmvcore::.("{first} vs {second}"), first = test1, second = test2)
   ```

   Row keys stay `paste(test1, "vs", test2)` (English), so the McNemar, Differences and summary
   lookups still match. `.performMcNemarTest()` and `.calculateDifferences()` gained a
   `comparison_label` argument. It is used for the displayed `comparison` cells and inside notices.
2. **Heatmap row label.** `"Gold Standard"` stays the internal factor level stored in the plot
   state. The label is translated at render time:

   ```r
   gold_label <- jmvcore::.("Gold Standard")
   ggplot2::scale_y_discrete(labels = function(x) ifelse(x == "Gold Standard", gold_label, x))
   ```

3. **The 3-test summary is two complete sentences.** The significant and non-significant Cochran
   paragraphs used to be assembled from English fragments, which no translator could reorder.
   Each is now one `sprintf` msgid with positional `%1$.2f` and `%2$s`.
4. **Percentages in report sentences.** `fmt_pct()` had a hard-coded `sprintf("%.1f%%", x)`, so a
   Turkish sentence read "... 85.0% ..." next to a translated "(%95 GA: %80.1-90.2)". It now uses
   `sprintf(jmvcore::.("%.1f%%"), x * 100)`, translated as `%%%.1f`, which gives `%85.0`.
5. **Non-ASCII caught.** The Edit tool decoded a `χ²` escape into a literal `χ²` in the
   merged msgid. It was restored to the 4-hex escape, the one form the jamovi extractor decodes.
   After that, `tools::showNonASCIIfile()` reports 0 and re-running `i18nUpdate()` leaves `tr.po`
   unchanged.

Strings deliberately left unwrapped are programmatic tokens: the `rowKey` values
`"Test Positive"` / `"Test Negative"` / `"Total"` (their displayed labels are wrapped) and the
heatmap state level `"Gold Standard"`.

| English | Turkish |
| --- | --- |

| TP / FP / FN / TN | GP / YP / YN / GN (as in the existing 2x2 footnotes) |

Style rules applied:

- **No case suffix on a placeholder.** A variable name can end in anything, so vowel harmony
  cannot be resolved. Sentences are built around a separate word ("%s testindeydi",
  "{test} için", "'{variable}' değişkeninin").
- **Panel and table names** match their existing Turkish titles: Önemli Bilgi, Yeniden Kodlanmış
  Veriler, Karar Testi Karşılaştırması, %95 Güven Aralığı ile Farklar, Güven Aralıkları.
- **Percent placement depends on the template type:**
  - `sprintf` templates: `%%95`, `%%%1$.1f`;
  - `.fmt()` templates and plain strings: `%95`, `%{pct}`;
  - `.a.yaml` descriptions spell it out ("yüzde 95"), because a literal `%` breaks the `.Rd`.
- **Clinical-tone guards are kept.** Wording such as "not a clinical recommendation" →
  "bir klinik öneri değildir" and "descriptive" → "betimsel" stays in every sentence that had it.

## 10. Addendum, 2026-10-01/02: recommended McNemar tests

The analysis switched to the McNemar versions that Fagerland, Lydersen & Laake (2013) recommend.
It now uses the mid-p test by default, and the new option `mcnemarMethod` offers the asymptotic
test without continuity correction. Five rounds of review followed. Every new or reworded msgid is
translated: **decisioncompare 490/490**.

- **Checks.**
  - `msgfmt -c` OK.
  - The release gate's sprintf rules find 0 problems in decisioncompare.
  - The Turkish runtime smoke ends with 0 problems. It ran 36 fixtures in both variants,
    including no discordant pairs, one discordant pair, the CI-disagreement cases, the 3-test
    Cochran Q = 30 case and the "Cochrane" variable name. It checked 296 English fragments, 109
    panel sentences and all 29 McNemar msgids.
- **Method labels.** `McNemar mid-p` and `McNemar asimptotik (süreklilik düzeltmesiz)`. Neither
  contains "test", because the Turkish sentence frame adds "testi" (`%1$s testi`).
- **Report sentences.** One complete sentence per variant, with no spliced label:
  - `%1$s ile %2$s testlerini karşılaştıran McNemar mid-p testi, tanısal doğrulukta anlamlı bir fark gösterdi (n = %3$d eşleştirilmiş olgu; p %4$s).`
  - `Süreklilik düzeltmesiz asimptotik McNemar testi, %1$s ile %2$s testlerini karşılaştırırken …`, followed by `χ²(%4$d) = %5$.2f, p %6$s`.
- **Glossary additions.**
  - mid-p → `mid-p`, as in decisioncombine, whose `orta-p` was aligned to `mid-p`.
  - asymptotic → `asimptotik`.
  - without continuity correction → `süreklilik düzeltmesiz`.
  - nominal significance level → `nominal anlamlılık düzeyi`.
  - "the value of no difference" → `fark olmamasına karşılık gelen 0 değeri`.
  - "tested (had discordant pairs)" → `test edilen (uyumsuz çifti olan)`.
  - complete enumeration → `tüm olası sonuçları sayarak`.
- **Static table note.** The McNemar table's fixed note is now actually translated. A folded
  `note: >` scalar had left a trailing newline, so the runtime string never matched its msgid;
  `note: >-` fixes that.
