# TinyTable Dataset Summary Information

Summary table providing overview of all TinyTable test datasets
including sample sizes, variable counts, descriptions, key features, and
recommended usage scenarios.

## Usage

``` r
tinytable_datasets_summary
```

## Format

A data frame with 6 observations and 7 variables:

- Dataset:

  Character. Dataset name

- Observations:

  Integer. Number of observations

- Variables:

  Integer. Number of variables

- Description:

  Character. Brief dataset description

- Key_Features:

  Character. Main features and characteristics

- Primary_Use_Case:

  Character. Primary testing scenario

- Recommended_Table_Types:

  Character. Suggested table types for testing

## Source

Generated by create_tinytable_test_data.R

## Details

This summary table provides a quick reference for all TinyTable test
datasets, helping users select appropriate datasets for their testing
needs and understand the key characteristics of each dataset.
