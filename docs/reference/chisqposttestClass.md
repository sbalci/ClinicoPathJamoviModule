# Chi-Square Post-Hoc Tests - Enhanced Implementation

Comprehensive post-hoc analysis for chi-square tests including residuals
analysis, pairwise comparisons, and multiple testing corrections.
Integrates methods from jamovi forum recommendations and best practices
from statistical literature.

## Details

This enhanced implementation provides three complementary approaches:

1.  Residuals Analysis - Identifies which cells contribute to
    significance (recommended first step)

2.  Pairwise Comparisons - Formal hypothesis testing between group pairs

3.  Comprehensive Analysis - Combines both approaches with educational
    guidance
