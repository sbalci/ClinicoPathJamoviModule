# TimeROC Test Datasets

Comprehensive collection of test datasets designed for validating
time-dependent ROC analysis functions. Each dataset represents different
clinical scenarios, biomarker types, and methodological challenges
commonly encountered in time-to-event analysis.

## Usage

``` r
data(timeroc_cancer_biomarker)

data(timeroc_cardiovascular_risk)

data(timeroc_multi_biomarker)

data(timeroc_landmark_biomarker)

data(timeroc_edge_cases)

data(timeroc_competing_risks)
```
