# Treemap

'Creates treemap visualizations for categorical data'

## Usage

``` r
jjtreemap(
  data,
  group,
  size,
  color = NULL,
  aspectRatio = 1.67,
  borderWidth = 0.7,
  borderLevel1Width = 1.5,
  borderLevel2Width = 0.5,
  borderLevel1Color = "black",
  borderLevel2Color = "gray",
  showLabels = TRUE,
  labelSize = 4,
  labelLevel1Size = 15,
  labelLevel2Size = 12,
  labelLevel1Color = "white",
  labelLevel2Color = "black",
  labelFontFace = "normal",
  labelBackground = "transparent",
  labelAlignH = "center",
  labelAlignV = "center",
  labelOverlap = 0.5,
  title = "",
  subtitle = "",
  caption = ""
)
```
