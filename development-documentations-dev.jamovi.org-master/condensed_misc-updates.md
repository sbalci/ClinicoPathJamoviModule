# API Updates (condensed)

- 2025-12-31 Image Sizing: jamovi 2.7.16 adds `setSize2` for R-based modules.
- 2025-11-11 New Analysis Action System: jamovi 2.7.12 (`Action` option, `perform()`).
- 2024-03-08 jamovi 2.5 series: R 4.3.2, CRAN snapshot 2024-01-09, better ARM/Apple Silicon; modules need a build per OS/arch; update `jmvtools`.
- 2019-07-08 Advanced UI customisation (jamovi 1.0.4+, not backward compatible with 0.x).
- 2017-06-09 Analysis state tutorial.
- 2017-04-20 jamovi 0.7.3 dev tools: isolated system libs, `.u.yaml` linked to `.a.yaml` labels, UI compiler modes `aggressive` (default) / `tame`.
- 2017-04-02 Dev mode and debugging (0.7.2.7).

Not on this page: jamovi 28.3 (File, Text), 28.4 (module support for opening external files), 28.7 (module support for exporting files); these appear only in https://www.jamovi.org/releases.html.
